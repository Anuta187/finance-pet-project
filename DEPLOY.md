# Запуск в Docker

```bash
docker compose up --build
```

После сборки приложение доступно на http://localhost:8080.

Данные сохраняются между перезапусками. Чтобы начать с чистой базы, выполните `docker compose down -v`.

Если запускаете не только у себя, задайте свой секрет для токенов:

```bash
JWT_SECRET=любая-длинная-строка docker compose up --build
```

# Деплой на Render

Пока проект нигде не развёрнут, но если понадобится:

1. Залить проект на GitHub.
2. Создать на Render Web Service для бэкенда: папка `backend`, тип Docker. В переменных задать `JWT_SECRET` и свой `ADMIN_PASSWORD`.
3. Создать второй Web Service для фронтенда: папка `frontend`, тип Docker. В переменной `API_UPSTREAM` указать адрес бэкенда.
4. Открыть адрес фронтенда.

На бесплатном тарифе сервис засыпает без запросов и первый раз открывается долго, а база сбрасывается при каждом перезапуске.
