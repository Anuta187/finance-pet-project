# Чек-лист

## Вход и регистрация
- [ ] Вход демо-клиентом и админом, кнопки демо-доступа подставляют данные
- [ ] Неверный пароль и неизвестный email дают одинаковое сообщение
- [ ] Email в другом регистре и с пробелами по краям при входе работает
- [ ] Регистрация с занятым email, слабым паролем, несовпадающими паролями показывает ошибки
- [ ] Без входа защищённая страница открывает /login, после входа возвращает обратно
- [ ] После «Выйти» токен удалён, кнопка «Назад» не показывает данные
- [ ] Перезагрузка страницы не разлогинивает
- [ ] Испорченный в DevTools токен выкидывает на вход с «Сессия истекла»

## Роли и безопасность
- [ ] Клиент не видит пункт «Администрирование», на /admin видит 403
- [ ] Админ после входа попадает в /admin
- [ ] Запрос без токена даёт 401, клиент на `/api/admin` получает 403
- [ ] Подмена id на чужой счёт, карту или автоплатёж даёт 404
- [ ] `"role": "ADMIN"` при регистрации игнорируется
- [ ] Заблокированный клиент не может войти, открытая вкладка выкидывает его на вход
- [ ] Админа нельзя заблокировать
- [ ] В ответах API нет полного номера карты и хеша пароля

## Счета и переводы
- [ ] Сумма на дашборде равна сумме остатков
- [ ] Открытие счёта: с остатком, без остатка, пустое название, 51 символ
- [ ] Перевод: с точкой и запятой, 0,01, весь остаток, остаток + 0,01, тот же счёт
- [ ] Дневной лимит: ровно 100 000 проходит, ещё 0,01 нет, у другого счёта свой лимит
- [ ] Кнопка «Перевести» неактивна, пока идёт запрос
- [ ] После ошибки введённые данные не стираются

## Карты
- [ ] Новая карта: маска номера, держатель латиницей, срок на 4 года
- [ ] Заблокированная карта серая и недоступна в форме оплаты
- [ ] После разблокировки картой снова можно платить

## Платежи и автоплатежи
- [ ] Оплата со счёта и картой, при оплате картой списывается её счёт
- [ ] Без категории или источника форма не отправляется
- [ ] Сумма больше остатка даёт ошибку
- [ ] Диаграмма расходов считает правильно, без оплат показывает пустое состояние
- [ ] Оплата не тратит лимит переводов
- [ ] Автоплатёж с датой в прошлом не создаётся
- [ ] Повторный запуск автоплатежей в тот же день не списывает второй раз
- [ ] Отключённый автоплатёж не исполняется
- [ ] Ежемесячный автоплатёж от 31-го числа не съезжает

## Прочее

- [ ] Swagger открывается, Authorize с токеном работает
- [ ] `docker compose up --build` поднимает приложение на :8080, данные сохраняются после перезапуска
- [ ] Вёрстка не ломается на 360 px
