# Видение продукта

«Личные финансы» — учебный интернет-банк. Клиент видит свои счета и карты, переводит деньги между своими счетами, оплачивает услуги и настраивает автоплатежи. Администратор видит всех клиентов и операции и может заблокировать доступ.

## Пользователи

- Клиент — ведёт свой бюджет: счета, переводы, платежи, карты, автоплатежи.
- Администратор — сотрудник банка: список пользователей, блокировка, журнал всех операций.

## Что входит

- регистрация и вход по email и паролю, JWT, роли CLIENT и ADMIN
- счета, переводы между своими счетами, история операций
- карты «Мир»: выпуск, блокировка, разблокировка
- оплата услуг по 8 категориям и диаграмма расходов за месяц
- автоплатежи раз в день, неделю или месяц
- админ-панель
- REST API со Swagger, запуск в Docker

Не входит: переводы другим людям, валюты кроме рубля, восстановление пароля, 2FA, refresh-токены, закрытие счетов и отмена операций.

## Бизнес-правила

| ID | Правило |
|---|---|
| BR-1 | Сумма больше 0, не больше двух знаков после запятой |
| BR-2 | Нельзя списать больше, чем есть на счёте |
| BR-3 | Переводы с одного счёта — не больше 100 000 ₽ за календарные сутки по времени сервера. Оплата услуг в лимит не входит |
| BR-4 | Нельзя перевести деньги на тот же счёт |
| BR-5 | Перевод выполняется целиком или не выполняется совсем |
| BR-6 | Название счёта от 1 до 50 символов, начальный остаток не меньше 0 |
| BR-7 | У каждой ошибки есть код и понятное сообщение |
| BR-8 | Email уникален без учёта регистра. Пароль от 8 до 72 символов, в нём есть буква и цифра. В базе хранится только хеш |
| BR-9 | Клиент видит только свои счета, карты, операции и автоплатежи. На чужие API отвечает 404, как будто их нет |
| BR-10 | Заблокированный пользователь не может войти, его токен перестаёт работать сразу |
| BR-11 | Платёж идёт либо со счёта, либо с карты. При оплате картой деньги списываются со счёта карты |
| BR-12 | Автоплатёж исполняется в свою дату, потом дата переносится на следующий период, даже если списать не получилось |
| BR-13 | Заблокированной или просроченной картой платить нельзя. Полный номер карты не хранится |
| BR-14 | Админ-API доступно только администратору. Администратора нельзя заблокировать, при регистрации роль всегда CLIENT |

## Допущения

- Деньги хранятся в копейках, поэтому нет ошибок округления.
- База H2, схема описана миграциями Flyway, так что переехать на PostgreSQL несложно.
- Номера карт генерируются, это не настоящие карты.
