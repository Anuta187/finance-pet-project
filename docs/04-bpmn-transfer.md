# BPMN: перевод между счетами

Схема лежит в [04-bpmn-transfer.bpmn](04-bpmn-transfer.bpmn), её можно открыть в Camunda Modeler или на demo.bpmn.io. Ниже та же логика упрощённо.

```mermaid
flowchart TD
    start([Клиент хочет перевести деньги]) --> fill[Выбрать счета и сумму]
    fill --> gw0{Счета выбраны?}
    gw0 -- Нет --> fill
    gw0 -- Да --> req[POST /api/transfers]
    req --> gw1{Сумма корректна?}
    gw1 -- Нет --> err[Показать ошибку]
    gw1 -- Да --> gw2{Счета разные?}
    gw2 -- Нет --> err
    gw2 -- Да --> gw3{Счета есть и свои?}
    gw3 -- Нет --> err
    gw3 -- Да --> gw4{Хватает денег?}
    gw4 -- Нет --> err
    gw4 -- Да --> gw5{Лимит не превышен?}
    gw5 -- Нет --> err
    gw5 -- Да --> post[Списать, зачислить, записать операцию]
    post --> ok([Перевод выполнен])
    err --> fail([Перевод не выполнен])
```

Перед переводом сервер проверяет токен и что пользователь не заблокирован. Всё от проверки счетов до записи операции идёт в одной транзакции, при ошибке она откатывается.
