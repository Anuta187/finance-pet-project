# Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | Перевод, оплата и автоплатёж выполняются целиком или не выполняются совсем. При ошибке остатки не меняются |
| NFR-2 | Деньги считаются в копейках, без ошибок округления |
| NFR-3 | API отвечает быстрее секунды при тысяче операций |
| NFR-4 | Интерфейс на русском, ошибки показываются рядом с формой |
| NFR-5 | Работает в последних Chrome, Firefox и Edge, вёрстка не ломается от 360 px |
| NFR-6 | Все эндпоинты описаны в OpenAPI, есть Swagger |
| NFR-7 | У важных элементов есть `data-testid`. Есть тестовый профиль с базой в памяти, сбросом данных и сдвигом времени |
| NFR-8 | Тесты запускаются в GitHub Actions, отчёт Allure сохраняется |
| NFR-9 | JWT подписывается секретом из `JWT_SECRET` и живёт 24 часа. Пароли хранятся только как BCrypt-хеш |
| NFR-10 | Клиент не видит чужие данные, блокировка срабатывает сразу, роль нельзя выбрать при регистрации |
| NFR-11 | Полный номер карты не хранится и не передаётся |
| NFR-12 | Входные данные проверяются на сервере, запросы к базе параметризованы, служебные эндпоинты есть только в профиле test |
| NFR-13 | Всё приложение запускается командой `docker compose up --build` |
| NFR-14 | Ошибка одного автоплатежа не влияет на другие, повторный запуск в тот же день не списывает деньги второй раз |

## Стек

- Бэкенд: Java 17, Spring Boot 3.5, Spring Security, JPA, Flyway, H2, jjwt, springdoc, Maven
- Фронтенд: React 18, TypeScript, React Router, Vite
- Тесты бэкенда: JUnit 5, Mockito, AssertJ, MockMvc
- Автотесты: JUnit 5, RestAssured, Selenide, AssertJ, Allure
- Инфраструктура: Docker, docker compose, GitHub Actions

Не сделано: отзыв токенов при выходе, 2FA, восстановление пароля, ограничение числа попыток входа, резервное копирование.
